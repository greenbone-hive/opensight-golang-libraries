# assetcategory Package Documentation

This package holds the canonical asset categories: the high-level group every
asset type belongs to. Callers write `assetcategory.Network` rather than the
string, so a typo is a compile error.

The type values and the type-to-category mapping live in the sibling
[assettype](../assettype/README.md) package; nothing here refers back to it.

## Example Usage

```go
if category == assetcategory.Database {
	applyDatabasePolicy(asset)
}

for _, c := range assetcategory.All {
	counts[c] = 0
}
```
